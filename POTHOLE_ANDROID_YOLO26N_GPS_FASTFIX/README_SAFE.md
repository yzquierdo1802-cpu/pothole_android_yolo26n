# Uso seguro

La app está diseñada para un teléfono montado de forma estable. No debe manipularse mientras una persona conduce. La detección es una ayuda experimental/operativa y no sustituye la atención del conductor ni un sistema automotriz homologado.

La georreferenciación es opcional y está desactivada por defecto. No existe permiso de Internet en el manifiesto de V12.
